Claude Code

Dicas e padrões para aproveitar melhor a IA e fazer com que ele crie com maior assertividade e qualidade.

Diferente de um chatbot que responde perguntas, o Claude Code pode ler seus arquivos, executar comandos, fazer alterações.

Explore, planeje e codifique

DICASepare a pesquisa e o planejamento da execução — assim você evita que Claude resolva o problema errado.

1 · EXPLORAR

Claude lê arquivos e responde perguntas sem alterar nada.

leia src/hooks/useAuth.ts e entenda como tratamos sessão e login
2 · PLANEJAR

Peça um plano de implementação detalhado.

/plan quero adicionar login com Google no NextAuth. quais componentes precisamos mudar?
3 · IMPLEMENTAR

Claude codifica e verifica o resultado contra o plano combinado.

implemente o fluxo do plano. escreva testes com Testing Library e rode a suíte

PULAR O PLANOTarefa pequena e óbvia — corrigir um tipo, renomear uma prop? Se você descreve o que muda em uma frase, pule o plano e peça direto.

Escreva um CLAUDE.md

CLAUDE.md é um arquivo especial que Claude lê no início de cada conversa. Inclua comandos Bash, estilo de código e regras de fluxo de trabalho. Isso dá ao Claude contexto persistente que ele não pode inferir apenas do código.

EXECUTE /init para gerar um arquivo CLAUDE.md inicial baseado na estrutura do seu projeto atual, depois refine ao longo do tempo.

✓ INCLUA

  • Stack e decisões fixas do projeto
  • Convenções que valem para o projeto inteiro,
  • Princípios de arquitetura, em uma linha
  • Termos internos do time mapeados para arquivos/pastas

× EVITE

  • Regras detalhadas de um tarefas (crie um skill)
  • Regras 100% mecânicas que um linter/formatter já garante
  • Práticas auto-evidentes como “escreva código limpo”
  • Documentação longa (link em vez disso)
CLAUDE.md
# Projeto
- Stack: React 18, Typescript, Material UI (MUI), Jest;

# Padrões de Código
- Exporte os componentes como exportações nomeadas (Named Exports).
- Importe utilizando o alias `@/` em vez de caminhos relativos `../../../`.

Comunique-se e deixe Claude te entrevistar

Trate Claude como um colega sênior

  • "Como funciona o gerenciamento de estado global aqui?"
  • "O que esse useEffect faz em Cart.tsx?"
  • Sem prompt especial — pergunte direto.

Para features maiores, inverta o jogo

Comece com uma descrição mínima e deixe Claude entrevistar você sobre implementação, e peça ao Claude para entrevistá-lo usando a ferramenta AskUserQuestion.

prompt · entrevista 
Quero construir um DataTable component reutilizável
com paginação e ordenação. Me entreviste em detalhes
usando a ferramenta AskUserQuestion.

Pergunte sobre implementação técnica, UI/UX, aprofunde-se nos pontos complexos 
que eu possa não ter considerado. Continue até cobrirmos tudo —
depois escreva um spec completo em SPEC.md.

DICACom o SPEC.md pronto, abra uma sessão nova e limpa só para implementar. O spec deve nomear arquivos, dizer o que fica fora do escopo e terminar com um passo de verificação ponta a ponta.

Gerencie sua sessão

A janela de contexto enche rápido — e o desempenho cai conforme ela enche. É o recurso mais importante para administrar em qualquer sessão.

janela de contexto/clear reinicia o ciclo
/clearReinicia o contexto entre tarefas não relacionadas
auto-compactionResume sozinho perto do limite de tokens
/compact <instruções>Você direciona o que preservar ao compactar
Esc Esc · /rewindResume só um trecho, mantendo o resto intacto
/btwPergunta rápida que nunca entra no histórico
subagentsInvestigam em contexto separado e só devolvem o resumo

SINALCorrigiu o mesmo problema duas vezes na sessão? O contexto está poluído com tentativas falhas — dê /clear e escreva um prompt melhor com o que aprendeu.

Crie skills

Skills dão a Claude conhecimento de domínio e fluxos reutilizáveis, carregados sob demanda — sem inchar o CLAUDE.md a cada sessão. Basta um diretório com um SKILL.md.

.claude/skills/component-conventions/SKILL.md 
---
name: component-conventions
description: ativada quando o usuário pede: 
  "crie um componente [Nome]"
---
## Passo a Passo:
1. Crie a pasta src/components/[Nome].
2. Gere o arquivo index.tsx usando o template abaixo:
   [Template de Código]
3. Crie o arquivo de testes [Nome].test.tsx

Como funciona

  • Claude aplica a skill automaticamente quando é relevante
  • Ou você invoca direto com /nome-da-skill
  • Fluxos com efeitos colaterais: use disable-model-invocation: true pra disparar só manualmente

CUIDADO! Instalar muitas skills e de fontes aleatórias pode gerar falhas de segurança, confundir a IA com informações conflitantes e aumentar o tempo de resposta e consequentemente aumentar os gastos de tokens.

Forneça um conteúdo rico

Claude infere intenção, mas não lê sua mente. Quanto mais precisos os dados que você entrega, menos correções você vai precisar fazer depois.

@arquivoReferencie arquivos com @ em vez de descrever onde o código vive — Claude lê antes de responder
ImagensCole ou arraste capturas de tela e imagens direto no prompt
URLsAponte para documentação e referências de API — libere domínios recorrentes em /permissions
PipeCanalize dados direto, ex.: cat error.log | claude
AutonomiaDeixe Claude buscar o que precisa sozinho, via Bash, MCP ou leitura de arquivos

POR QUÊDados brutos removem ambiguidade. Uma captura de tela do design, o log de erro real ou o arquivo referenciado com @ valem mais que qualquer descrição por escrito.

Evite padrões de falha comuns

Reconhecer esses erros cedo economiza tempo — e a maioria tem uma correção simples.

×

Sessão pia-de-cozinha

Você mistura tarefas soltas na mesma conversa. O contexto vira ruído.

Correção: /clear entre tarefas não relacionadas.

×

Corrigindo em loop

Mesmo erro, mesma correção, de novo. O contexto está poluído com tentativas falhas.

Correção: após 2 tentativas, /clear e um prompt melhor.

×

CLAUDE.md inchado

Regras demais e Claude ignora metade — a importante se perde no meio.

Correção: poda impiedosa; vire hook o que for automático.

×

Confiança sem verificação

A implementação parece plausível mas não trata os casos extremos.

Correção: sempre peça teste, script ou print. Sem verificação, não envie.

×

Exploração infinita

"Investiga isso" sem escopo — Claude lê centenas de arquivos e enche o contexto.

Correção: escopo estreito, ou delegue a um subagent.

A intuição pra evitar esses padrões vem da prática — preste atenção no que funciona.
